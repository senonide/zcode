# Code of conduct

Zcode is a GNOME application and adopts the GNOME project
[Code of Conduct](https://conduct.gnome.org/) in full. It applies to every
project space: issues, pull requests, commit messages and code review.

In short: be respectful, assume good faith, and keep discussion on the work
rather than the person doing it.

To report a violation, follow the reporting process described in the
[GNOME Code of Conduct](https://conduct.gnome.org/), or open an issue if the
matter can be discussed publicly.
